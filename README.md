# qp-DKP oscillator: reproducible calculations

Version **1.0.1**, 10 November 2026. Author: **Azmi Ali Altintas**.

This package accompanies *Spectral and Thermostatistical Properties of a
Two-Parameter (q,p)-Deformed Hamiltonian Extension of the Spin-One DKP
Oscillator*. It computes **Tables I–V, all 13 figures, and the numerical
cutoff/precision checks** from the defining positive-energy spectrum.
No external dataset or Mathematica installation is required.

## Repository and archival record
The source code, documentation, reference numerical data, and figure-generation scripts are publicly available on GitHub:

https://github.com/altazm-art/qp-dkp-reproducibility

The initial release (v1.0.0) has been deposited on Zenodo:

https://doi.org/10.5281/zenodo.24083788

The DOI covering all archived versions is:

https://doi.org/10.5281/zenodo.24083787

The package provides the calculations for Tables I–V, all 13 manuscript figures, and the associated numerical validation checks.

This v1.0.1 maintenance release updates repository/archive metadata,
release verification and file-integrity hashes; it does not alter the
oscillator model or numerical algorithms. The frozen `reference_results/`
records retain their original v1.0.0 run metadata as provenance.

## Install and run

Use Python 3.10 or newer; the complete run was tested with the environment
recorded in `tested_environment.json` (Python 3.12). A second complete
run for v1.0.1 used Python 3.13.5 with the same recorded package versions
and reproduced all archived numerical results and 13 PDFs byte-for-byte
(see `RELEASE_CHECK.json`). Install dependencies:

```bash
python -m pip install -r requirements.txt
python reproduce_all.py --output-dir reproduced
```

For the exact dependency versions used in the recorded check, use
`requirements-lock.txt` in a matching Python environment. The default run
recomputes all tables, plot data and independent high-precision checks.
It prints progress after each stage. The high-precision audits can take
longer than the ordinary sums; actual timings are in the supplied run summary.
No calculation reads the supplied reference outputs as input.

In Colab/Jupyter, upload/extract this directory and run:

```python
%run reproduce_all.py --output-dir reproduced
```

A faster exploratory run omits only the independent arbitrary-precision
audits; the table calculations and all figures are still regenerated:

```bash
python reproduce_all.py --output-dir quick_run --quick
```

## Generated output

The default `reproduced/` directory contains:

- `data/table_I.csv` through `data/table_V.csv`;
- full baseline and adaptive thermal data;
- the 51×51 contour, 201-point fixed-Sigma slice and 155 spectral points;
- 404 fixed-Sigma peak coordinates;
- small-r and matched NR/DKP thermal curves;
- independent 60-, 70-, 80-, 100- and 110-digit check records;
- `figures/`, containing all 13 vector PDF figures;
- `figure_map.csv`, `figure_validation.json`, `run_summary.json` and hashes.

The PDF filenames intentionally match the LaTeX manuscript. Some filenames
retain historical figure numbers; **FIGURE_MAP.csv gives the current numbering**.
Generated PDFs can therefore be copied directly beside the manuscript TeX.
Numerical results, rather than PDF creation timestamps, define reproducibility.
PDF timestamps are omitted to make repeated plotting more deterministic.

## Physics conventions

The calculation uses q=exp(nu), p=exp(mu), mu>=0 and nu>0, together with
the undeformed origin. The finite-energy accumulation edge nu=0, mu>0 is
excluded because its canonical sum diverges. Relativistic calculations use
r=hbar*omega/m>0 and tau=kB*T/m. The helper r=0 denotes the **matched NR
excitation spectrum**, not a substitution into the relativistic temperature.

There is one positive-energy state per oscillator level and ordinary
Boltzmann–Gibbs weights. `F`, `U`, `S`, `C` are the dimensionless quantities
F_phys/m, U_phys/m, S_phys/kB, C_V/kB. Small-r plots use the shifted partition
sum and excitation energy to expose thermal structure below the rest-energy
scale without underflow of the common rest-energy Boltzmann factor.

Large temperatures, including tau=10^100, examine the formal restricted
canonical model. The script reproduces the discrete logarithmic correction;
a unit coefficient for C*ln(tau) is labelled a **continuum guide**, not a
universal exact discrete limit.

## Validation and scope

Every table entry is checked at the printed precision. The peak searches,
cutoff changes and independent arithmetic audits are recorded separately.
A terminal Boltzmann-weight threshold is **not** treated as a bound on the
whole omitted tail. See NUMERICS.md for the raw-moment bounds and their
propagation to observables. Decimal precision denotes arithmetic precision,
not a certified number of correct digits in every plotted point.

The one-parameter comparison evaluates the reference paper's printed
approximate partition function literally, with all observables differentiated
from that same function. It separately checks the corrected fixed-level
coefficient. No published plot is digitized, and no copyrighted reference PDF
is included. Original calculation/plotting conventions recovered from the
author's archived scripts are described in PROVENANCE.md.
